# Accounting digest backend

Fetches Greek accounting/tax sources, keeps only relevant items, extracts deadlines **from the source text**
(each one shown with the snippet it came from), holds items for your review, and outputs a digest.
Python 3.9+, standard library only. Nothing is generated by an AI, so nothing can be invented.

## Setup

1. Check the sources (the URLs in `sources.json` are unverified guesses):

       python3 digest.py check-sources

   Fix or disable (`"enabled": false`) any that fail or show 0 items. `rss` sources need a feed URL;
   `html_links` sources need a `link_pattern` regex that article URLs match.

2. Daily flow:

       python3 digest.py fetch          # new items go to the review queue
       python3 digest.py review         # see pending items and extracted deadlines
       python3 digest.py approve ID...  # or: approve --all   /   reject ID...
       python3 digest.py digest         # print the digest (--format json for a webapp)

3. Deliver:

       export TELEGRAM_BOT_TOKEN=...   # from @BotFather
       export TELEGRAM_CHAT_ID=...     # channel or group id
       python3 digest.py send-telegram

   Each item is sent once; deadlines are repeated while 7 days or fewer remain.

4. Web interface: `python3 digest.py serve --port 8080`, then open http://localhost:8080
   (files in `web/`: `index.html`, `styles.css`, `app.js`). It shows deadlines by urgency with the source
   quote, news, topic filters, search, and a "copy as text" button for pasting into WhatsApp or email.
   The same server exposes `GET /digest.json?days=2` (read-only).
   Set `DIGEST_API_KEY` to require an `X-API-Key` header on the JSON; the page then asks for the key once
   per browser tab. Put the server behind HTTPS (e.g. a reverse proxy) before exposing it publicly.
   The page must be served by this same server; opening `index.html` as a file will not work.

5. Review page: open http://localhost:8080/review.html (or the "Έλεγχος" button). It lists pending items
   with the source excerpt and the extracted deadline. You can fix or clear a deadline date, approve or
   reject items (one by one or in bulk), and undo the last action. It needs the admin key: `serve` prints a
   random one at startup, or set `DIGEST_ADMIN_KEY` to keep a fixed key. The review endpoints are always
   locked behind it, even when `DIGEST_API_KEY` is not set.
   Endpoints: `GET /api/pending`, `POST /api/review` `{"ids":[...],"action":"approve|reject|undo"}`,
   `POST /api/deadline` `{"id":"...","deadline":"YYYY-MM-DD"|null}`, all with header `X-Admin-Key`.

## Cron (08:00 daily)

    0 8 * * * cd /path/to/accounting-digest && python3 digest.py fetch && python3 digest.py send-telegram

Without a review step, add `--auto-approve` to `fetch`. Do that only after a few weeks of checking output.

## Notes

- Items from sources with `"store_excerpt": false` (e.g. Taxheaven) keep only title and link.
- Deadlines without a year are guessed from the publish date and flagged "(το έτος υποτέθηκε)".
- Dedupe is by URL and title. Items older than `max_age_days` (default 14) are skipped.
- Tests: `python3 -m unittest -v test_digest` (offline).
- WhatsApp: use `digest --format text` and send it through the official WhatsApp Business API,
  or keep paying subscribers on Telegram/email.
